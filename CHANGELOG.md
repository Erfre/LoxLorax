# Changelog

## 1.0.7

- Added an F8 live toggle that restores vanilla visuals or reattaches the replacements immediately.
- Saved the enabled state between game sessions.
- Added an on-screen enabled/disabled message.
- Verified live disable and re-enable in an isolated Valheim world.

## 1.0.6

- Corrected Vile bind-pose mapping relative to the native root bone.
- Matched the replacement paws to native toe contact without changing animation timing.
- Verified 30 native Vile clips across 150 sampled poses.
- Corrected scale handling in the cosmetic death snapshot.

## 1.0.5

- Added the separate undead Vile replacement with ribs, back spines, decayed coloring, and glowing eyes.

## 1.0.4

- Added the detached-head and sky-launch death effect.
- Moved the legs closer beneath the body.
- Made the living lox bite easier to see.
