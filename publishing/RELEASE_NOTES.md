# Lox Lorax 1.0.8

Adds the missing in-game preview images to the Thunderstore details page. The mod itself is unchanged from 1.0.7.

## Included

- Living orange lox replacement.
- Separate undead Vile (`Unbjorn`) replacement.
- Native 17-bone animation retargeting.
- Paw-grounding correction for Vile locomotion.
- Visible living-lox bite motion.
- Detached-head and sky-launch cosmetic death effect.
- F8 live enable/disable toggle with saved state.

## Requirements

- Valheim 1.0.20 / Steam build 25909357, or a compatible later build.
- BepInExPack Valheim 5.4.2351.

This is a client-side visual mod. Servers do not need it. See the README for installation, configuration, validation details, known limits, AI disclosure, and fan-project disclaimer.

Valheim does not award Steam achievement progress while BepInEx is loaded. Launch the game in vanilla mode when earning achievements.
